# Peasant Homebrew Tap

This repository is the Homebrew tap for [Peasant](https://github.com/peasant-labs/peasant).

Peasant publishes its macOS Homebrew package as a cask generated by Goreleaser during final releases. Release candidates do not update this tap.

## Install

```bash
brew tap peasant-labs/tap
brew install --cask peasant
peasant --version
```

## Repository Layout

```text
Casks/peasant.rb
```

`Casks/peasant.rb` is generated and updated by the Peasant release workflow. Do not edit it by hand unless the release automation is being repaired.
